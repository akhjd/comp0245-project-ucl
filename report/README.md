# Report working outline

Use the course LaTeX IEEE template. Maximum six report pages per the supplied brief.

1. Introduction: task, assumptions, constraints and scope.
2. Methodology: expert collection, representations, splits, model, training and justified choices.
3. Results: experimental protocol, baselines, actual tables/plots, generalisation, robustness, efficiency and interpretation.
4. Conclusion: limitations and supported improvements.

Keep a separate contribution statement of at most one page, optionally page seven. Name each member and describe their actual implementation, experimental and writing contributions. No names or results have been fabricated here.
